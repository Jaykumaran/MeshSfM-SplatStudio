Generate a mesh

Poses: TUM (t tx ty tz qx qy qz qw), KITTI (3x4 rows), COLMAP model, name + quaternion / 4x4 tables; matched by name, timestamp or order. Poses win over GPS. GPS only: KISS-SLAM (LiDAR) or COLMAP SfM, then aligned to the GPS track. Without poses or GPS the result is in its own frame (use Align).
Use masks (masks/ folder: cars, people, sky ...)

RGB: fast dense MVS (photometric only, depth for every 2nd image)
The result is added as a mesh layer (+ its point cloud) and the drive path is taken from the poses.

Splat from the same capture

Exports a generated mesh's capture as a COLMAP model: its images + poses, with its LiDAR / MVS points as the initial point cloud. Train it with any 3DGS trainer; the splat lands in the mesh frame (no alignment).
Keep the trainer from re-centring / re-scaling the scene, then add the trained .ply as a splat layer (z up). See the README for an example.

Drive path

Draw the path you want to drive along - on the top-view map or on the 3D surface (any view, even eye level) - then use it.
Map: click points, Enter finishes. 3D: Shift+click points on the surface, Esc finishes. The mesh is re-chunked along the new path (do it before editing: earlier edits go to a backup folder).

Align layers

Side by side: the moving layer on the left, the fixed one on the right, same camera (a splat and a mesh)
Pick point pairs (Inspect tool): click a spot on the moving layer, then the same spot on the fixed one - side by side: left, then right. Rough clicks are fine - they are a starting guess and soft anchors, and mis-clicks are dropped.
